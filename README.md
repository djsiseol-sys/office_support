# 근무 일지

사업장(초소)마다 쓰던 수기 근무일지를 디지털로 옮긴 내부용 도구.

- **지금 근무 상황을 실시간으로 본다.** 첫 화면(`현황`)에 초소마다 지금 누가 서 있는지,
  직전 근무가 무엇을 넘겼는지가 뜬다. 특이사항은 그 자리에서 한 줄로 올린다
- **파일 하나로 돌아간다.** `index.html` 을 브라우저에서 열면 바로 쓸 수 있다.
  빌드 도구·프레임워크·npm 의존성이 없다
- **양식을 설정으로 정한다.** 일지에 어떤 칸이 있는지를 코드가 아니라 화면에서 정한다 —
  초소를 늘리거나 서식이 바뀌어도 코드를 고치지 않는다
- **여러 사람이 동시에 쓴다.** 일지 한 건이 서버의 한 행이라 서로 덮어쓰지 않는다
- **근무일지에는 사람 이름이 들어 있다.** 로그인하지 않으면 본문을 보여주지 않는다

## 처음 여는 사람

1. `index.html` 을 브라우저에서 연다 (서버 없이도 동작한다 — 이 브라우저에만 저장된다)
2. 함께 쓰려면 **`서버설치안내.md`** 를 따라 Supabase 를 붙인다.
   **3단계 RLS 는 반드시 켠다**
3. `⚙ 설정` 에서 로그인한다

## 작업을 이어받는 사람

**`이관노트.md` 를 먼저 읽는다.** 시설 예약 대장에서 무엇을 가져왔고 무엇을 버렸는지,
어디를 먼저 고쳐야 하는지가 거기 있다.
작업 규칙은 **`CLAUDE.md`** 에 있다.
